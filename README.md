# Fintech Dashboard

A modern and responsive fintech dashboard built with React and TypeScript.

## Features

- Financial overview dashboard
- Balance and bank card components
- Spending analytics and charts
- Quick action interface
- Transaction management
- Transaction filtering and search
- Responsive design
- Dark mode UI

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- React Router
- Recharts
- Framer Motion
- React Icons
